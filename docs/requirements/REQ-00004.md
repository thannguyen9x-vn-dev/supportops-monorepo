## 1. Brief Requirement (Input từ PO)

> TENANT_ADMIN muốn xuất báo cáo vận hành (request volume, SLA health, team performance, service type breakdown) ra file CSV, Excel, hoặc PDF để gửi nội bộ hoặc lưu trữ. Đây cũng là cơ hội để tích hợp Python file-processing vào project thực tế.

---

## 2. Context & Background

- **Module liên quan:** Reports (trang mới) + AI Service (`apps/ai-service/`)
- **Trạng thái hiện tại:** Trang Reports ❌ chưa có — cần tạo mới; AI Service ✅ có `GET /ask` và `db/queries.py` với 5 metrics đã sẵn
- **Cơ sở dữ liệu cho export:** `get_report_data()` trong `apps/ai-service/db/queries.py` đã trả về đủ dữ liệu cho tất cả 5 metrics — không cần thêm query mới
- **Kiến trúc proxy:** NestJS verify JWT → inject `x-tenant-id` header → forward sang Python service. Export endpoints sẽ theo đúng pattern này
- **Constraint quan trọng:** `apps/ai-service` hiện là **READ-ONLY** — export hoàn toàn phù hợp vì chỉ đọc dữ liệu và stream file về

## 3. Detailed Requirements

### 3.1 Functional Requirements

| ID | Requirement | Priority |
|---|---|---|
| FR-001 | TENANT_ADMIN có thể export báo cáo ra file `.csv` từ trang Reports | Must Have |
| FR-002 | TENANT_ADMIN có thể export báo cáo ra file `.xlsx` (Excel, nhiều sheet) từ trang Reports | Must Have |
| FR-003 | TENANT_ADMIN có thể export báo cáo ra file `.pdf` từ trang Reports | Should Have |
| FR-004 | User chọn khoảng thời gian (from_date / to_date) trước khi export | Must Have |
| FR-005 | User chọn metrics muốn export (mặc định: tất cả 5 metrics) | Should Have |
| FR-006 | File tải về có tên gồm date range, ví dụ: `report_2026-01-01_2026-03-31.xlsx` | Must Have |
| FR-007 | Excel export có nhiều sheet: Summary + 1 sheet/metric, header row được format (bold, màu) | Should Have |
| FR-008 | PDF export có section title và bảng dữ liệu cho từng metric | Should Have |
| FR-009 | NestJS expose proxy endpoints `POST /api/v1/export/csv|excel|pdf` forward sang Python service | Must Have |

### 3.2 Non-Functional Requirements

| ID | Requirement |
|---|---|
| NFR-001 | Export phải hoàn thành trong vòng 10 giây với tối đa 10,000 records |
| NFR-002 | Tenant isolation: mỗi export chỉ chứa dữ liệu của tenant đó (`x-tenant-id` từ JWT, không từ body) |
| NFR-003 | Không lưu file tạm trên server — stream thẳng về client (`StreamingResponse`) |
| NFR-004 | Error phải trả về HTTP 400/500 với message rõ ràng, không expose stack trace |
| NFR-005 | `pnpm typecheck` và `pnpm lint` pass cho phần NestJS proxy |

## 4. Acceptance Criteria

- [ ] AC-001: TENANT_ADMIN gọi `POST /api/v1/export/csv` với `from_date`, `to_date` hợp lệ → nhận file `.csv` download với `Content-Disposition: attachment`
- [ ] AC-002: TENANT_ADMIN gọi `POST /api/v1/export/excel` → nhận file `.xlsx` có sheet "Summary", "Status Breakdown", "SLA Health", "Team Performance", "Service Types"
- [ ] AC-003: TENANT_ADMIN gọi `POST /api/v1/export/pdf` → nhận file `.pdf` có section title và bảng dữ liệu
- [ ] AC-004: Nếu `to_date < from_date` → trả về HTTP 400 với message "to_date must be >= from_date"
- [ ] AC-005: Nếu `metrics` chứa giá trị không hợp lệ → trả về HTTP 422
- [ ] AC-006: User không phải TENANT_ADMIN gọi export → NestJS trả về 403
- [ ] AC-007: Tenant A không thể nhận dữ liệu của Tenant B (test bằng cách đổi JWT và verify data trong file trả về)
- [ ] AC-008: File tên đúng format `report_{from_date}_{to_date}.{ext}`
- [ ] AC-009: Export với 0 record vẫn trả về file hợp lệ (không crash), chỉ có header row

## 5. Scope Boundaries

**IN SCOPE:**
- 3 Python export endpoints trong `apps/ai-service/routers/export.py`
- `exporters/csv_exporter.py`, `exporters/excel_exporter.py`, `exporters/pdf_exporter.py`
- NestJS proxy module `apps/api/src/modules/export/` (controller + service forward sang Python)
- Cập nhật `requirements.txt` với `openpyxl` và `fpdf2`
- Trang Reports mới (`/reports`) dành riêng cho TENANT_ADMIN: date picker + nút export CSV / Excel / PDF
- Route `/reports` được thêm vào navigation, chỉ hiện với role TENANT_ADMIN

**OUT OF SCOPE (không làm trong task này):**
- Import dữ liệu từ file (bulk create requests, import users) — scope riêng, cần service khác vì ghi DB
- Biểu đồ/chart trong PDF (chỉ bảng số, không chart)
- Scheduled/automated export (gửi email định kỳ) — feature riêng
- Export từ các module khác (Request List, Team Management) — chỉ Dashboard metrics trong task này
- Preview file trước khi tải (render inline trong browser)

## 8. Risks

| Risk | Mức độ | Mitigation |
|---|---|---|
| File lớn (~10k records) → timeout hoặc memory spike | Med | Dùng `StreamingResponse` — không buffer toàn bộ trong RAM; set timeout 30s ở NestJS proxy |
| `fpdf2` không hỗ trợ font tiếng Việt mặc định (thiếu Unicode) | High | Cần embed DejaVu font hoặc dùng thư viện khác (reportlab); Tech Lead quyết định |
| Trang Reports là trang mới hoàn toàn — cần thiết kế UI từ đầu | Med | Tech Lead cần quyết định layout (filter panel + export actions) trước khi FE implement |
| NestJS proxy timeout nếu Python service chậm | Low | Set `httpx` timeout 30s trong NestJS service, trả lỗi 504 rõ ràng |
