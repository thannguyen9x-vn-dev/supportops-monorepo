## 2. Context & Background

- **Module liên quan:** `apps/ai-service` — Python FastAPI service (standalone, ngoài pnpm workspace)
- **Trạng thái hiện tại:**
  - ✅ Source code đầy đủ: `main.py`, `routers/ask.py`, `adapters/`, `db/queries.py`, `tools/report_tool.py`
  - ❌ **Hoàn toàn chưa có test suite** — không có `test_*.py`, `pytest.ini`, hay `pyproject.toml`
  - ❌ `requirements.txt` chưa có `pytest` và các test dependencies
- **Context liên quan:**
  - `apps/ai-service` là read-only service — không INSERT/UPDATE/DELETE
  - `tenantId` luôn lấy từ `x-tenant-id` header do NestJS inject — không bao giờ từ body
  - Adapters (Anthropic + OpenAI) dùng `MAX_ITERATIONS = 5` để tránh tool loop vô hạn
  - DB queries dùng `asyncpg.Connection` — cần mock khi test
- **Scope update (PO confirm 2026-04-07):**
  - ✅ Enforce coverage threshold **≥ 80%** trong CI
  - ✅ Thêm `apps/ai-service` vào GitHub Actions CI pipeline
  - ✅ **Có** test startup failure case trong `main.py`
  - ✅ Có (roadmap) export/import CSV/Excel/PDF — sẽ tách REQ riêng nếu làm feature

## 3. Phân Tích — Scope Testing

### Các module cần test

| Module | File | Độ phức tạp test |
|---|---|---|
| Tool schema & parser | `tools/report_tool.py` | Thấp — pure functions, không cần mock |
| DB Queries | `db/queries.py` | Trung bình — cần mock `asyncpg.Connection` |
| Anthropic Adapter | `adapters/anthropic_adapter.py` | Cao — cần mock Anthropic SDK + tool loop |
| OpenAI Adapter | `adapters/openai_adapter.py` | Cao — cần mock OpenAI SDK + tool loop |
| Ask Router | `routers/ask.py` | Cao — cần mock adapters + DB pool + FastAPI TestClient/AsyncClient |
| App startup/shutdown | `main.py` | Trung bình — validate env + init pool/adapters + shutdown close |

### Chiến lược Mock

> **Nguyên tắc:** KHÔNG gọi API Anthropic/OpenAI thật (tốn tiền), KHÔNG kết nối DB thật.
> Tất cả external dependencies đều phải được mock bằng `pytest-mock` / `AsyncMock`.

> **Hardening requirement:** Tránh mock response sai structure (test pass nhưng prod crash).
> Cần tạo fixtures/factories mock response objects bám sát shape SDK thực tế.

## 10. Risks

| Risk | Mức độ | Mitigation |
|---|---|---|
| `pytest-asyncio` config sai → async test bị skip silently | Trung bình | Dùng `asyncio_mode = auto` trong `pytest.ini`; verify bằng `pytest -q` + `-v` |
| Mock Anthropic/OpenAI response sai structure → test pass nhưng logic thật sai | **High** | **FR-013**: tạo factories/fixtures mock response objects bám sát shape SDK; refactor tests dùng chung |
| `asyncpg.Connection` có nhiều methods khó mock (`.fetch()`, `.fetchrow()`) | Trung bình | Dùng `AsyncMock` + fixture trong `conftest.py`; hạn chế surface mock |
| `httpx` version không tương thích với FastAPI | Thấp | Pin `httpx>=0.27.0` trong requirements |
| CI runtime thiếu Python deps | Trung bình | Update GitHub Actions: setup-python + pip install -r requirements.txt; cache pip |
| Coverage flakiness do logging/branching | Thấp | Target coverage folder-level; exclude `__init__.py`; add tests cho fallback branches (unknown stop_reason/finish_reason) |
